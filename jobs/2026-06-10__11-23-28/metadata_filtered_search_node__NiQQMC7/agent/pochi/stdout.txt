# Mem0 Platform — Metadata-Tagged Memory + V2 Filtered Retrieval (Node.js) ## Background A productivity assistant stores per-user notes in **Mem0 Platform** so they can be retrieved later by topic. Each note is tagged with a custom metadata `category` (one of `finance`, `travel`, `health`) and a `priority` (`high` or `low`) at write time. Later the app issues **v2 compound filter queries** to return only the memories that match a specific category, and audits one memory's update history. Your job is to write a Node.js (ES-module) script that uses the **managed Mem0 Platform** SDK — the default `MemoryClient` export from the `mem0ai` npm package — to: 1. Ingest five notes for a single user, each carrying a different `metadata` payload. 2. Use `client.getAll({ filters: ... })` with a **v2 compound `AND` filter** on `user_id` + `metadata` to retrieve only the notes tagged with `category: "finance"`. 3. Use `client.search(query, { filters: ..., topK })` to perform a semantic search over the same user's notes with another compound filter on `user_id` + `metadata.priority`. 4. `update()` one of the finance memories with new text and pull its full change `history()`. 5. `delete()` the low-priority health memory. 6. Write JSON artifacts and a structured stdout log.
