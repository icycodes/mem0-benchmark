## How it works (`/home/user/bulk-import/ingest.sh`)
1. **Idempotency** — any pre-existing memories scoped to `harbor-bulk-import-${ZEALT_RUN_ID}` are deleted before each run.
2. **Ingestion** — each of the four preference statements is added with `mem0 add "<text>" --user-id <uid> --output json`. Because the platform returns a `PENDING` event rather than an immediate memory ID, the script polls `mem0 event status <event_id> --output json` (up to 20 × 1-second retries) until the event reaches `SUCCEEDED`, then extracts `data.results[0].id` as the real memory UUID.
3. **Search** — `mem0 search "dietary restrictions" --user-id <uid> --top-k 5 --output json` is executed; the result array length is counted with `jq`.
4. **Log** — `/home/user/bulk-import/output.log` is (re)created from scratch on every run.
